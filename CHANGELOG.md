# Changelog

All notable changes to UsageOne. Each version's section is used as the notes of its GitHub release, and UsageOne shows them in Settings when an update is available.

## 1.0.0

### New
- **Claude usage in the tray**: the 5-hour session, the weekly limits (and per-model ones when your plan has them), when each resets, your plan and the peak hours, in a panel styled like the Windows flyouts. Light and dark theme.
- **No sign-in**: the numbers come from Claude Code, using the sign-in it already has. No tokens are spent.
- **Bar colour**: the Windows accent colour, white, green or a colour of your own.
- **Stream Deck plugin**: a key with the session and weekly bars. Tap to refresh, hold to open Claude. Install it from Settings → Stream Deck.
- **Updates from Settings**, with what's new.
- **Starts with Windows** from the first run. You can turn it off in Settings.
